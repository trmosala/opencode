# Embedded document state qualification

Issue: [#39](https://github.com/trmosala/opencode/issues/39). This document records the embedded-state acceptance audit on 3 October 2026. It contains only public runtime information, behavioral observations and loaded-item counts. No event titles, account identifiers, attendee details, calendar URLs, screenshots or report/message content are retained here.

The authenticated acceptance run used CookieMonster's actual bundled browser plugin, utility-process sidecar and main-process browser routing. The user enabled Agent Access once for the Teams tab. `browser_read_state` then exposed its embedded Outlook calendar, and `browser_click` expanded hidden entries and changed the calendar view without an additional embedded-origin approval. This is evidence from the live CookieMonster tab, rather than a Teams desktop or standalone browser observation.

The visible week initially covered 28 September–4 October 2026. The calendar was also read in day view across 26 September–2 October, navigating backwards through all seven days. The loaded counts reconciled as follows:

## Acceptance audit

| Requirement                                                                                                                    | Evidence and boundary                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |

Prior serial Windows native runs passed `--embedded-documents`. Live Teams supplied the authenticated nested-calendar parity check. |
| Document and interactive references bind native identity                                                                       | Frame references belong to the registered native tab, owner/session, source revision, access revision, exact native frame/loader and execution context. Aggregate document records report `closed_shadow_dom` and canvas/nonsemantic visual omissions, with screenshot observation available under the same tab grant. Native embedded and visual qualification previously passed.                                                                                                                                                                                 |
