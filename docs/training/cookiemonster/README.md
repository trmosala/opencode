# CookieMonster training for motion designers

This course teaches CookieMonster as a creative production system, not as a chat box and not as a compressed computer-science degree.

## Recommended course

1. **The machine behind the magic — Node and the coding harness (60 min)**
   Learn what executes code, what the model does, what the harness does, and why project scope and verification matter.
2. **Files, folders, projects, and Git (60 min)**
   Learn the source-of-truth model: where work lives, how paths work, what changed, and how work can be recovered.
3. **Briefing an agent like a production team (60 min)**
   Turn creative intent into an objective, constraints, references, acceptance criteria, and a verification request.
4. **Plan, Build, permissions, and review (75 min)**
   Explore read-only, approve bounded actions, inspect diffs and outputs, and recover when a run goes wrong.
5. **Motion-design workflows (90 min)**
   Apply the loop to batch utilities, asset preparation, expressions/scripts, data-driven graphics, and project documentation.
6. **Capstone: one real team workflow (90 min)**
   Each learner completes a small real task and explains the evidence that makes the result trustworthy.

## Teaching rule

Do not begin with JavaScript syntax. First give learners the system map:

> intent → harness → model decision → tool action → changed project → verification

Syntax becomes useful later, when a learner needs to read or adjust a small piece of code. It is not the entry ticket for using CookieMonster responsibly.
